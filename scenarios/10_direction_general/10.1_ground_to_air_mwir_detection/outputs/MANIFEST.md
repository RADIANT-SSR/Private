`scripts/run_ground_to_air_mwir_detection.py` from
`inputs/ground_mwir_tracker_data.xlsx` (itself generated by
`inputs/create_spreadsheet.py`). Regenerate by running the script from the repo root:

```bash
python scenarios/10_direction_general/10.1_ground_to_air_mwir_detection/scripts/run_ground_to_air_mwir_detection.py
```

## Provenance of the MODTRAN anchor

`modtran/real_runs/` is gitignored (Geometry-Flexibility plan §7.1), so a fresh clone
cannot regenerate `ground_to_air_modtran_anchor.png` or the anchor stars on
`ground_to_air_sky_path_vs_zenith.png`. Both were generated 2026-07-28 with the
owner-delivered batch-1 runs K1–K6 staged, invoked as:

```bash
python scenarios/10_direction_general/10.1_ground_to_air_mwir_detection/scripts/run_ground_to_air_mwir_detection.py \
    --modtran-runs modtran/real_runs
```

Run provenance for K1–K6: `docs/plans/modtran_run_matrix.csv`; the same files are pinned
by `tests/integration/test_uplooking_horizontal_anchors.py`. The measured comparison
numbers are transcribed into `walkthrough.md` §10 so the record survives without the
files.

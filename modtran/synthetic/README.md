# Synthetic Tape7 Outputs — Pipeline/Scenario Exercise Only

**This is not MODTRAN. This is not physics validation data.** Every file
here (`*.synthetic.tp7`) is generated by `scripts/generate_synthetic_tape7.py`
so RADIANT's MODTRAN backend, `Tape7Reader`, and scenarios 1.1/6.2 can be
exercised end-to-end before real MODTRAN access is available. Do not
use these files to close Gap 38, Gap 39, or CU-011 — those need a real,
independently-run MODTRAN (or donated real tape7s), which is what
`docs/plans/MODTRAN_Run_Matrix_Plan.md` and `modtran/decks/` are for.

## Regenerate

```
python scripts/generate_synthetic_tape7.py            # all 39 runs
python scripts/generate_synthetic_tape7.py --run-id A1  # one run, debug
```

First run takes ~20–30 minutes (216 HITRAN line-by-line calls across 8
unique atmospheric columns, parallelized and cached under `_cache/`).
Re-runs after that only pay for runs not already cached.

Not committed (Rule 26 — deterministic from the CSV + these scripts;
`.gitignore` excludes `*.tp7` and `_cache/` here).

## What's genuinely independent physics, and what isn't

| Column | Source | Independent of RADIANT? |
|--------|--------|--------------------------|
| `TOT TRANS` | HITRAN line-by-line (RADIS) on an independently-built 9-layer atmosphere | **Yes** — real spectroscopic line data, not RADIANT's Beer-Lambert band fit |
| `PTH THRML` | Multi-layer Planck/Schwarzschild emission using the same HITRAN-derived layer optical depths | **Yes** |
| `SOL SCAT` / `SNGL SCAT` | Simplified single-scatter estimate (Koschmieder visibility + Ångström power law + isotropic phase function) | **No** — same tier of approximation as RADIANT's own `SimpleAtmosphere` aerosol model, independently re-implemented but not independently *sourced*. Not multiple-scattering DISORT. |
| `SURF EMIS`, `THRML SCT`, `GRND RFLT`, `DRCT RFLT` | Not modeled — written as 0 | Legitimately zero for this matrix: every row has `surface_albedo_surref = 0`, and ground/surface thermal emission is out of scope here |

## Known physics gaps vs. real MODTRAN

- **No Rayleigh scattering.** VIS/UV transmittance is under-attenuated —
  only molecular absorption and the simplified aerosol term are included.
- **No multiple scattering.** The single-scatter aerosol estimate cannot
  reproduce DISORT's diffuse-sky contribution, especially at short
  wavelengths and in hazy atmospheres.
- **Simplified vertical structure.** Only each profile's sea-level
  temperature and total precipitable water are matched to the published
  McClatchey et al. 1972 values; lapse rate, tropopause height, and
  water-vapor scale height use a single ICAO-standard shape for every
  profile, not the profile-specific AFGL structure MODTRAN's MODEL 1–6
  cards actually use. See `scripts/synth_modtran/layers.py` for the full
  derivation and citations.
- **Plane-parallel, no refraction.** Slant paths use a secant airmass
  factor, not true ray-tracing with Earth curvature/refraction.
- **IEMSCT=3 (Block E, ground-level solar irradiance) reuses the
  radiance-shaped tape7 columns** rather than MODTRAN's actual
  irradiance-mode output format — `TOT TRANS` holds direct-beam solar
  transmittance and `SOL SCAT` holds the diffuse estimate, `PTH THRML`
  is zero (no thermal term modeled for these runs). A real MODTRAN
  IEMSCT=3 tape7 has different columns entirely.
- **Unvalidated against any external benchmark.** This is a new,
  from-scratch implementation (`scripts/synth_modtran/`), checked
  internally (Planck output verified against the Stefan-Boltzmann
  integral — see `scripts/synth_modtran/tests/test_emission_sanity.py`)
  but never compared to LBLRTM, real MODTRAN, or field measurements.
